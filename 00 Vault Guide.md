# Vault Guide
How this vault is organized, for jesse and for Claude.

## Folders
| Folder | What goes in it |
| --- | --- |
| `00 Campaign Hub` | Where the campaign stands right now. Update after every session. |
| `Party/` | One note per player character, with their D&D Beyond sheet. |
| `Sessions/` | [[Session Log]], one note per arc so far, then one note per session from Session 16 on. |
| `Plot Threads/` | One note per ongoing story thread, each with its dramatic question. |
| `People/` | NPCs and named creatures. |
| `Factions/` | Courts, noble houses, the Hunt, the Wardens, rebels. |
| `Cities/` | Settlements, with subfolders for Serenthia's rings and Tajir's merchants. |
| `Regions/` | Large areas and bodies of water. |
| `Fey Realm/` | Places in the fey realm. |
| `Events/` | Major historical or campaign events. |
| `Objects/` | Items, herbs, random tables. |
| `Templates/` | Blank notes to copy. |
| `Inbox/` | Raw notes waiting to be filed. |

At the top level, [[Namaris]] holds the world's history and [[Fey Portals]] the portal war.

## Conventions
- **Properties** at the top of each note: `type` (pc, npc, merchant, faction, city, district, location, region, event, item, thread, arc, session), `status`, plus `location`, `faction` or `region` where they apply.
- **Links:** link every proper noun with `[[Name]]` the first time it appears in a note. Notes are linked by name, so file names must be unique.
- **Secrets:** anything the players don't know goes in a `> [!secret] DM only` callout.
- **Unknowns:** gaps go under a "Not decided yet" heading, never guessed.
- **Sources:** the session history comes from the campaign bible jesse exported from their planning chat on 2026-10-10.

## After each session
1. Copy [[Session Template]] into `Sessions/` and fill it in.
2. Update [[00 Campaign Hub]]: last scene, where everyone is, next session.
3. Update every NPC, place and thread that changed. Add new notes for anything new.

## Running style
The campaign follows The Angry GM's rules, run in the style of Matt Mercer, Griffin McElroy and Brennan Lee Mulligan: every scene has a dramatic question, every PC gets a spotlight, villains act when the party doesn't, and the table's best improvisations become canon.

## Not part of this campaign
The separate "Obsidian Vault" folder in Documents (Italian regions) is unrelated.
